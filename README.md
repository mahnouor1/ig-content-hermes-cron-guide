# The 8AM Cron Lead Engine

A one-page guide showing how one chat message becomes a daily 8 AM job that fills a CRM with fresh leads.

Static site: everything is in `index.html`. No build step.

To update: edit `index.html`, then

```
git add . && git commit -m "update" && git push
```

Each push to `main` redeploys on Vercel.
